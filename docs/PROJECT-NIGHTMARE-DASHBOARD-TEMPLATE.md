# Project Nightmare — New Dashboard Design Template

Locked visual direction: **3D + RETROWAVE + HORROR + INDUSTRIAL DECAY + NEON GLITCH**

## Core palette
- The Void: #0B0C10, #1F2833
- Decay & Surveillance: #2C3531, #4E5D4C
- The Neon Glitch: #FF0055, #00F0FF
- Terminal Horizon: #8B00FF, #FF5500

## Dashboard structure
1. Cinematic 3D/retrowave hero
2. Project Nightmare command deck
3. Six live development consoles
4. 3D environment module grid
5. Core palette module
6. Technical footer / surveillance motif

## Scene language
- Rain-soaked industrial/research architecture
- Neon magenta and cyan reflections
- Purple/orange horizon glow
- Sickly green/olive decay tones
- Deep void shadows
- Perspective grids, scanlines and restrained HUD graphics
- Original Project Nightmare visual identity

## World continuity
- Mansion lobby remains the fixed start.
- Procedural spaces follow beyond the controlled start.
- Nightmares remain illusions unless explicitly specified.
- Horror effects should support gameplay and navigation.
- Future pages inherit this visual language.

## Implementation
The dashboard is rendered through js/ui/pages.js and shared styling in css/nightmare.css.
