# Project Nightmare — Asset Source Library

This is the master staging area for downloaded and externally sourced game assets.

## Rules

- Keep original source files intact.
- Keep licence/readme information with sourced assets where available.
- Do not place release-ready assets directly in this folder.
- Approved assets are catalogued, optimised, and copied into the appropriate build pack by the asset pipeline.
- Uncertain assets should be placed in `_DROPZONE/` until their licence is verified.
