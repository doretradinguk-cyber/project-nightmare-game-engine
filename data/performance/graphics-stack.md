# Graphics Stack

Project Nightmare now has a Three.js visual-upgrade path alongside the original low-level WebGL renderer.

**Pipeline:** Asset Vault -> GLB/GLTF + PBR textures -> Three.js scene -> procedural Mansion -> lighting/shadows/fog -> gameplay systems.

## Targets
- PBR-ready surfaces
- local room lighting and emergency red accents
- dynamic shadows
- atmospheric fog
- reusable GLB props
- desktop/Android quality scaling
- self-hosted release assets

3. Decals/grime.
