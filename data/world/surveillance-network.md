# Surveillance Network

The Mansion contains an abandoned security network.

## Components

- fixed cameras
- room identifiers
- motion detection
- door state
- lighting state
- signal quality
- event timestamps
- unknown-subject classification
- corrupted playback

## Signature Mechanic

Some feeds may display an event shortly before it occurs in the physical environment.

The feed must never be a guaranteed oracle. It can degrade, lose frames, contradict another camera or display an unidentified subject.

## Player Interaction

The player can:
- switch cameras
- inspect timestamps
- mark suspicious frames
- operate selected doors
- investigate motion alerts
- compare camera feeds
- discover hidden feeds

## Horror Rule

The surveillance system should occasionally reveal something the player could not see from their current position, but it should not constantly provide answers.
