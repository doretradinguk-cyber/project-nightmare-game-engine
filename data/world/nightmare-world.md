# Project Nightmare — World Foundation

## Four Pillars

1. **Living Architecture** — the Mansion is an adaptive horror environment. Rooms, lighting and environmental details can change after player actions.
2. **Surveillance Network** — cameras, terminals, motion sensors and corrupted feeds form an interactive information layer.
3. **Nightmare Console** — the development/control interface is part of the fiction and can expose systems, assets, memories and environmental state.
4. **The Laughing Jester** — an original recurring entity that begins as a digital/pixel anomaly and progressively manifests in the physical world.

## Visual DNA

Project Nightmare combines grounded domestic horror, cinematic survival-horror structure and tactical surveillance language while maintaining an original visual identity.

Core materials:
- damp concrete
- aged plaster
- oxidised metal
- dirty glass
- failing fluorescent tubes
- analogue control panels
- CRT-style displays
- corrupted pixel imagery
- rain and glyph streams

## World Rule

The environment must never become visually noisy simply for spectacle. Every effect should either establish mood, communicate information, foreshadow an event or respond to player behaviour.

## Originality Rule

No copied characters, maps, interfaces, names, logos, music, dialogue, textures or distinctive scenes from external games. Genre references are used only to guide broad atmosphere and systems thinking.
